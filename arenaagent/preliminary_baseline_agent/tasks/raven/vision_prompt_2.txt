你正在解一道 3×3 瑞文图形矩阵。

输入有两张图：
- 第一张是题目矩阵，缺失格为“?”；
- 第二张是按 1~8 编号的候选项。

随题的【像素测量】会给出形状、填充、面积、宽高和多图形槽位。
图像用于理解整体排列与方向；精确的形状、灰度和尺寸比较优先用像素测量。

目标是先预测缺失格的属性，再找唯一匹配候选，不要从候选倒推一个牵强规律。

【必须执行的求解步骤】

1. 分别建立属性表

对 8 个已知格分别记录：
- count：图形数量；
- shape：形状/边数；
- fill：白、浅灰、中灰、深灰、黑；
- size：同类图形内的相对大、中、小；
- orientation/position：仅在确有重复规律时使用；
- 多图形时分开上/下、左/右或固定位置槽。

不同属性通常遵循不同规律，必须分开推导。

2. 对每个属性寻找最简单、可重复验证的规律

按以下顺序检查：
- 每行或每列恒定；
- A/B/C 循环、Latin square 或每行/列各出现一次；
- 有序增减、数量加减或大/中/小等级排列；
- 相同的复制、合并、差集，但只能在两个完整行/列都能验证时使用。

一条规律必须同时解释多个已知格。只解释一行、一列或一对格子的“故事”不算规律。

3. 防止过拟合

- 不要因为第一行和第三行有两个相似格，就假设“第三行是第一行的旋转/放大版”。
- 只有已知列都显示同一旋转量，且中间行/列也不冲突时，旋转才是规律。
- 不要仅因某候选与任意一个已知格尺寸最近就选它。先从行列规律得出目标尺寸等级，再找对应候选。
- 不要把菱形和方形当成两种边数；它们都是四边形，方向另行判断。
- 题面中有边框、问号、候选编号，它们都不是图形。

4. 多图形格必须结构化

先判断图形数量和位置槽，再对每个槽独立推导 shape/fill/size。
不要把上下两个形状当成一个组合图形，也不要忽略图形数量和位置。

5. 候选筛选与回填

按硬约束依次筛选：
count/槽位 → shape/边数 → fill → size → orientation/position。
将候选回填缺失格，重新检查每条使用过的规律。
如果回填后只能解释一个局部而破坏其他属性表，则换候选。

【输出】

不要输出逐步思维链。只输出一个 JSON 对象，不要 Markdown：
{"reason":"一句话说明目标格的 count/shape/fill/size 及关键行列规律","answers":[1],"confidence":0.85}

answers 必须只有一个 1~8 的整数，并严格按第二张图上方的编号作答。
